## 第四条　安全测试边界

声明方明确本次参赛相关安全与功能测试的边界如下：

1. **不对生产防火墙或真实业务资产下发封禁、隔离等不可逆动作**；响应类验证以自动化契约、审批/白名单逻辑、回滚幂等及（如启用）dry-run/软执行路径为主。
2. **不修改生产代码作为本次测试迭代目标**；测试以既有工作树与 Compose `:dev` 全栈为对象。
3. **不登录 Grafana / Kafka UI 做口令爆破或凭证强度测试**（凭证未纳入本次证据包）；管理面暴露风险在报告中以信息级披露。
4. **不将白盒安全审计中的攻击路径以真实 payload 对运行实例复现**；历史审计结论用于风险披露与加固参考，不作为「已全部修复」的背书，除非另有专项关闭证明。
5. Agent 守卫测试强调按拦截层取证；**组合绕过套件尚未系统化**，声明方不得声称组合攻击已被穷尽。

凡超出上述边界的演示需求，须另行书面批准，并采取隔离环境、只读探测或仿真拓扑。
